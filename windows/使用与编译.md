# 五点轮询连点器 1.0.0

适用于 Windows 11 x64。独立运行版为单文件 `FivePointClicker.exe`，包含 .NET 10 桌面运行时。首次启动时，运行时会解压必要的组件到临时目录。以普通用户身份运行即可。

## 使用步骤

1. 打开程序。把指针移到目标位置并按 **F6**，最多添加五点。也可用「添加坐标」填入当前鼠标位置，再双击表格修改 X、Y。坐标是实际屏幕像素，可输入副屏的负坐标。
2. 每点可选择左键、右键或中键、单击或双击、执行次数和启用状态。选中一行后可上移、下移或删除。执行顺序从表格顶端向下，跳过禁用行。
3. 选择无限循环、指定轮数或指定运行时间。默认点间隔 5 ms、轮间隔 10 ms、倒计时 3 秒。将两个间隔都设为 0 可启用最快提交方式。将倒计时设为 0 可立即启动。
4. 点击「开始」或按 **F8**，在倒计时内切换到目标窗口。运行时再次按 F8 可暂停，再按一次从原进度继续。按 **F9** 或点击「停止」结束本轮任务，可重新开始。
5. 快捷键框支持 F1–F24（F12 保留）及组合键，例如 `Ctrl+Alt+F9`。修改后点击「应用键位」。注册失败时界面提示冲突，已生效的键位保留。

点间隔仅在点位切换时使用，最后一点到下一轮首点使用轮间隔。同一点的多次执行连续发送。一次双击发送两组按下和释放，运行统计计作两次实际点击。Windows 或目标程序可按其双击规则解释很短时间内同位置、同按键的连续单击。指定运行时间按实际运行累计，暂停和倒计时不计入。界面统计的是成功提交给 Windows 的点击。

## 配置

「保存 JSON」可导出指定文件，「加载 JSON」会恢复表格顺序、启用状态、鼠标按键、次数、运行参数和快捷键。「删除配置」可选择并确认删除导出的 JSON。正常关闭时会将当前配置保存至 `%LOCALAPPDATA%\FivePointClicker\settings.json`，重开时恢复配置且保持待机。

## 编译与验证

安装 [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)，将源码 ZIP 解压，在源码目录中运行 PowerShell：

```powershell
dotnet build .\App\FivePointClicker.csproj -c Release
dotnet publish .\App\FivePointClicker.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -o .\publish
```

发布文件位于 `publish\FivePointClicker.exe`。复测时先关闭连点器主程序，退出占用 F6、F8、F9 的软件。在未锁定的交互桌面运行：

```powershell
$fixturePath = Join-Path ([IO.Path]::GetTempPath()) ("five-point-verify-" + [Guid]::NewGuid() + ".json")
dotnet run -c Release --project .\Verify\Verify.csproj -- $fixturePath
```

验证会打开置顶接收窗口、移动指针、输入测试键位，约需三分钟。测试期间让接收窗口保持可见并避免操作鼠标。测试接收窗口只处理程序自己标记的按键事件。验证项目不引用第三方库。

## 实际限制

- Windows 使用一个系统指针。程序向同一个输入流顺序提交移动、按下和释放；0 ms 表示程序不插入指定间隔，实际耗时仍受系统调度、桌面钩子、目标窗口处理速度和机器负载影响。已经提交的批次会由 Windows 继续处理，F9 取消后续提交。 [Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)
- 程序按 Per-Monitor V2 DPI 感知运行，使用虚拟桌面像素和绝对坐标映射，检查点位是否落在实际显示器上。监测到桌面布局变化时会停止。实际验证环境是一块 2560×1440、100% 缩放的显示器；多屏、负坐标与混合 DPI 仍需要在对应硬件环境复测。 [Microsoft MOUSEINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)
- 目标软件可能限制合成输入或需要更大的间隔。Windows 的 UIPI 要求目标的完整性级别等于或低于连点器。实际速率优先以目标接受的点击频率为准。 [Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)
