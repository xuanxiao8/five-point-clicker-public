## 功能

- 在 WPF 界面使用的视图模型中新增并修改 A–E 五行，使用 Win32 读取每个测试坐标。五点顺序和循环顺序由接收窗口校验。
- 混合配置按 A→B→C→E 执行，跳过禁用的 D，涵盖左、右、中键、双击和配置次数；40 轮收到 320 次点击，顺序、坐标及释放全部匹配。
- 测试默认 3 秒倒计时期间取消、无限循环、固定轮数、定时停止、暂停时冻结运行计时、从暂停进度恢复。
- 通过后台全局 F6 获取坐标，F8 启动、暂停并恢复零间隔引擎，F9 停止时检查三种鼠标键全部释放、此后无新事件。F9 输入发出至界面完成状态切换的一次示例为 31.20 ms，含测试轮询和界面调度。
- 检测 Windows 全局快捷键占用并成功注册不同的 Ctrl+Alt 组合键。
- JSON 完整往返与删除通过。另用独立配置路径验证 WPF 窗口关闭时保存，重开窗口恢复且保持待机。

## 连续运行

首轮 120 秒运行少收到一组按下和释放。逐条比较因此从首个缺失位置起发生序列错位。该次未记录每批的外部输入及测试钩子拦截计数，单次缺失的原因仍未确定。

加入外部输入和测试拦截计数后，从头重跑全部测试。在 1 ms 点间隔、10 ms 轮间隔下连续运行 120.001 秒，完成 3,063 整轮及下一轮 4 点，收到全部 15,319 次点击（30,638 个按键事件）。最大坐标偏移 0 px，未发现顺序错误、外部鼠标事件或测试拦截，进程按定时正常结束。CPU 为整机口径 0.30%。进程私有内存起始 150.7 MiB，中间采样 138.9–141.7 MiB，结束 141.6 MiB，期间未出现持续单向增长。该窗口为两分钟验证，适用于此次测试条件。

多屏、负坐标和混合 DPI 暂无对应实体显示环境的实测数据。原始复测日志随报告附上，源码 ZIP 中包含 `Verify` 项目，可复现实测。
