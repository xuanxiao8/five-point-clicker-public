# 五点连点器 Android 版 1.0.0

原生 Java APK，最低 Android 8.0（API 26），目标 API 35。使用 Android 无障碍服务执行触摸，手机无需 Root。安装包有本地签名，适合直接安装。实测使用 Android 12 模拟器，尚未接入实体手机。

## 安装与使用

1. 将 `FivePointAndroid.apk` 传到手机，点开安装。手机可能要求给打开 APK 的文件管理器授权安装来源。
2. 打开「五点连点器」，点「开无障碍」，在系统设置开启「五点连点器」服务。如果 Android 13 或更高版本提示「受限设置」，可在系统的「应用 → 五点连点器 → 应用信息 → 更多」查看「允许受限设置」。具体菜单由设备决定。 [Android 帮助](https://support.google.com/android/answer/12623953)
3. 返回应用，点「显示悬浮栏」，切换到目标应用。每次按「取点」，再轻触目标位置，可按顺序录入 A–E。按住悬浮栏顶部状态文字，可拖动工具栏避开目标坐标。
4. 按悬浮栏「开始」，默认倒计时 3 秒。悬浮栏可暂停、继续和停止。点右上角 × 可停止并隐藏。
5. 回主界面可手动增删、调整坐标和顺序、选择单击或双击、设置次数与启用状态。支持无限循环、指定轮数或运行时间，自动保存参数并可导入、导出 JSON。

点间隔默认 25 ms，轮间隔默认 40 ms。两个间隔都可设为 0。每次通过 Android 系统提交一个短触摸，等待手势结果再发下一次，因此 0 ms 代表免去额外延时。手动触摸可能中断在途手势，目标应用能否接受触摸也会影响结果。锁屏、熄屏或屏幕方向改变后，当前任务会停止。屏幕方向或分辨率变化后，请重新录入坐标。 [Android 手势接口](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService#dispatchGesture(android.accessibilityservice.GestureDescription,%20android.accessibilityservice.AccessibilityService.GestureResultCallback,%20android.os.Handler))

## 构建与验证

解压源码，准备 JDK 21、Android SDK Platform 35、Build Tools 35.0.0。在 Windows PowerShell 中运行：

```powershell
.\build.ps1 -AndroidJar "$env:ANDROID_HOME\platforms\android-35\android.jar" `
  -BuildTools "$env:ANDROID_HOME\build-tools\35.0.0" -JavaHome $env:JAVA_HOME `
  -OutputDir .\dist -Keystore .\keys\local.jks
```

脚本会先执行 JVM 逻辑测试，然后编译资源和 DEX、打包、签名并验证 APK。生成的签名密钥可以用于之后覆盖安装自己编译的版本。首次更换签名时，先导出配置，卸载旧 APK 后再安装并导入。源码也包含 `android-test` 中的独立触摸日志接收器。

## 实际测试

- JDK 逻辑测试 11 项通过，涵盖五点顺序、单点多次和双击、禁用和重排、倒计时取消、固定轮数、运行时限、暂停续跑和手势失败处理。
- APK 签名验证通过（v2、v3）。在 Android 12（API 31）720×1280 模拟器安装启动。启用服务后，从单独的接收应用通过悬浮层实际录入五点并核对保存的坐标。
- 默认间隔条件下，接收器记录到 **220 次完整触摸**（440 条按下和抬起事件）。从第一次按下至最后一次抬起耗时 **10.487 秒**，约 **20.98 次/秒**，顺序全部吻合，最大坐标偏移 0 px。停止后观察 0.8 秒未收到新事件。
- 暂停和继续测试收到 54 次完整触摸。开始暂停时，接收器还记录到一组按下和系统取消事件。等待 1 秒期间无后续触摸，继续后按设定顺序执行。
- APK SHA-256 为 `20679BFE202BCB7D8C13EAF0B51EC0FAA8E78D62F36EF789795FE90C0FBBC484`。真机、不同品牌系统、安卓其他版本与长期运行未验证。
